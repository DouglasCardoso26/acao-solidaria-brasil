# 🌍 Ação Solidária Brasil — Atividade 1

## 🎯 Objetivo
Esta primeira entrega tem como foco a **estruturação completa do HTML5** de um site institucional para uma ONG fictícia chamada **Ação Solidária Brasil**.  
O projeto visa criar uma base semântica e organizada para evoluir nas próximas etapas (CSS3, Responsividade e Interatividade).

---

## 🧱 Estrutura da Entrega
O projeto foi desenvolvido com as principais seções de um site institucional:

- **Cabeçalho (Header):**  
  Contém o logotipo e o menu de navegação principal.

- **Seção Hero / Início:**  
  Apresenta o título e o propósito da ONG.

- **Seção Sobre Nós:**  
  Descreve a missão, visão e valores da instituição.

- **Seção Projetos:**  
  Introduz os três pilares principais de atuação:
  1. Segurança Alimentar  
  2. Educação e Oficinas  
  3. Inclusão Digital

- **Seção Como Ajudar:**  
  Explica como o visitante pode contribuir com doações ou voluntariado.

- **Seção Contato:**  
  Disponibiliza formulário para envio de mensagens e dados de contato.

- **Rodapé (Footer):**  
  Mostra informações complementares e direitos autorais.

---

## 🧩 Tecnologias Utilizadas
- **HTML5 Semântico**
- Estrutura organizada em **seções** (`<header>`, `<main>`, `<section>`, `<footer>`)
- Uso correto de **headings hierárquicos**
- Elementos de **acessibilidade básica**
- Estrutura pronta para receber CSS e JavaScript nas próximas etapas
